# 首版开发里程碑

当前仅完成需求定义，以下实现工作尚未开始。

## M0 需求与仓库

- 编写首版 PRD，明确启动后自动执行、附件简历不在首版范围。
- 建立公开 GitHub 仓库，提交 PRD、README、许可与忽略规则。
- 明确参考项目的代码使用边界。

交付物：可审阅且纳入版本控制的文档。

## M1 规则与状态

- 实现并测试配置校验、薪资和字段筛选。
- 区分本次跳过、已沟通、发送前失败和待核对。
- 实现发送前记录、持久化去重、单任务锁与额度。

验收重点：AC-04、AC-05、AC-09、AC-10、AC-11、AC-14、AC-18。

## M2 搜索与发送

- 实现关键词遍历、列表变化核验、原生筛选及翻页。
- 实现目标岗位和会话核验、自定义及默认话术路径。
- 加入发送证据、停止检查、验证码和限制暂停。

验收重点：AC-01、AC-02、AC-03、AC-06、AC-07、AC-08、AC-12、AC-15、AC-16、AC-17。

## M3 界面与恢复

- 实现设置弹窗、进度日志、待核对列表与人工核对入口。
- 处理弹窗关闭、内容页面刷新、后台休眠和异常终止。
- 检查无凭据或真实数据进入仓库。

验收重点：AC-08、AC-09、AC-12、AC-13、AC-18。

## M4 首版验收

- 完成 PRD 全部自动化验收场景。
- 在用户实际账号下，经授权进行少量真实页面验收。
- 记录浏览器版本、页面适配日期、已知限制和验收结果。
- 达到标准后发布 v0.1.0，提供开发者模式安装说明。

尚未完成真实验收的构建不得标为已验证可用。
