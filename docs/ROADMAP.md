## M1 规则与状态（已完成）

实现位于 `src/core/`：`config.js` 配置校验与快照，`filter.js` 卡片筛选，`ledger.js` 发送记录、去重、额度与任务锁。实现约定：

- 经验、学历配置为可接受取值列表，卡片显示「经验不限」「学历不限」时视为满足；求职类型仅在 M2 通过平台原生筛选核验。
- 薪资仅为平台原生档位代码（PRD 0.3），卡片层不复核薪资。
- 发送前失败（尚未点击）不占额度，同一任务内最多重试一次；平台明确拒绝与结果不明均进入待核对。
- 任务锁 30 秒心跳过期；同一任务与标签页重复获取活锁不改状态，其他持有者不能接管活锁。过期锁拒绝发送和续心跳，须重新获取；首次获取或接管过期锁时，遗留的未定尝试转为待核对。
- ledger 只在后台 service worker 中创建一个实例，所有写操作串行执行。

- 实现并测试配置校验、薪资档位校验和卡片字段筛选。
- 区分本次跳过、已沟通、发送前失败和待核对。
- 实现发送前记录、持久化去重、单任务锁与额度。

验收重点：AC-04、AC-05、AC-09、AC-10、AC-11、AC-14、AC-18。

## M2 搜索与发送（代码完成，未在真实页面运行）

实现位置：

| 目录 | 内容 |
| --- | --- |
| `src/page/` | 选择器、搜索 URL 构造与核验、页面读取、阻断检测、选中卡片、滚动加载、点击与成功弹窗判定 |
| `src/core/run-state.js` | 任务运行状态、停止标志、一次性导航令牌 |
| `src/runner/task-runner.js` | 任务执行器：关键词遍历、筛选核验、逐岗处理、额度与暂停 |
| `src/background/`、`src/content/`、`src/shared/rpc.js` | 后台持有唯一的 ledger 与 run 存储；内容脚本经消息调用 |

实现约定：

- 每个关键词构造带城市和筛选参数的 URL 整页打开，加载后核验 URL 参数和筛选框已选状态，不一致即暂停。
- 求职类型、经验、学历各最多选一个平台选项，以便与平台单个筛选项一一对应并核验。
- 成功只认点击后出现的「已向BOSS发送消息」弹窗（MutationObserver 捕获，默认 5 秒超时）；弹窗未自动消失时只点「留在此页」。
- 点击前再次检查停止标志；已持久化但未点击的尝试用 `cancelAttempt` 撤销并退回额度。
- 心跳由独立定时器每 10 秒发送；记录结果失败（锁已被重新获取）时按待核对处理并暂停。
- 首版暂停即结束本次任务，释放任务锁；继续需重新开始。
