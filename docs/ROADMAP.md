# 首版开发里程碑

M0、M1 已完成；M2 起尚未开始。

## M0 需求与仓库

- 编写首版 PRD，明确启动后自动执行、附件简历不在首版范围。
- 建立公开 GitHub 仓库，提交 PRD、README、许可与忽略规则。
- 明确参考项目的代码使用边界。

交付物：可审阅且纳入版本控制的文档。

## M1 规则与状态（已完成）

实现位于 `src/core/`：`config.js` 配置校验与快照，`salary.js` 薪资解析，`filter.js` 卡片筛选，`ledger.js` 发送记录、去重、额度与任务锁。实现约定：

- 经验、学历配置为可接受取值列表，卡片显示「经验不限」「学历不限」时视为满足；求职类型仅在 M2 通过平台原生筛选核验。
- 薪资支持 K 与「万」（按 10K 折算）月薪写法，忽略「·N薪」；含年、天、时单位的一律无法判定。
- 发送前失败（尚未点击）不占额度，同一任务内最多重试一次；平台明确拒绝与结果不明均进入待核对。
- 任务锁 30 秒心跳过期；获取锁或无存活锁时，遗留的未定尝试转为待核对。
- ledger 只在后台 service worker 中创建一个实例，所有写操作串行执行。

- 实现并测试配置校验、薪资和字段筛选。
- 区分本次跳过、已沟通、发送前失败和待核对。
- 实现发送前记录、持久化去重、单任务锁与额度。

验收重点：AC-04、AC-05、AC-09、AC-10、AC-11、AC-14、AC-18。
