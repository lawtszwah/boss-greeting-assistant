# BOSS Greeting Assistant

BOSS 直聘网页端自动打招呼助手，计划以 Chrome Manifest V3 浏览器扩展实现。

用户设置关键词、筛选条件、招呼语和任务额度后，扩展自动搜索岗位、筛选、去重并发起沟通，记录可以核验的结果。启动后无需逐个岗位确认。

## 当前状态

当前阶段为需求定义，尚未实现或发布扩展。产品范围与验收以 [首版 PRD](docs/PRD.md) 为准。

首版包含多关键词搜索、条件筛选、自动打招呼、发送核验、历史去重和任务控制。附件简历发送、AI 匹配、定制简历、HR 自动回复均不属于首版。

## 开发与版本控制

- `main` 保存经过检查的文档和可用版本。
- 功能开发使用 `codex/` 前缀分支，通过 Pull Request 合并。
- 首个实现版本目标为 `v0.1.0`；当前 PRD 文档版本为 `0.1`。
- 不提交账号凭据、浏览器资料、真实简历、聊天记录、个人投递历史或含个人信息的截图。

## 使用边界

本项目与 BOSS 直聘无隶属或合作关系。自动化操作存在账号限制或封禁风险；任务额度和操作间隔不代表平台允许或保证账号安全。遇到验证码、访问限制或登录失效时停止，交由用户在原平台处理，不绕过平台限制。
