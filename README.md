# BOSS Greeting Assistant

BOSS 直聘网页端自动打招呼助手，Chrome Manifest V3 浏览器扩展。

用户在平台设置好默认招呼语，并在扩展中设置关键词、筛选条件和任务额度后，扩展自动搜索岗位、筛选、去重并通过「立即沟通」发起沟通，记录可以核验的结果。启动后无需逐个岗位确认。

## 当前状态

已发布 v0.1.1：2026-11-26 在 Chrome 157 和真实账号下完成首版验收（见 [验收记录](docs/ACCEPTANCE.md)）。验收记录列出了尚未在真实页面覆盖的场景。产品范围与验收以 [首版 PRD](docs/PRD.md) 为准。

首版包含多关键词搜索、条件筛选、自动打招呼、发送核验、历史去重和任务控制。插件内自定义招呼语、附件简历发送、AI 匹配、定制简历、HR 自动回复均不属于首版。

## 安装与使用（开发者模式）

1. 从 [Releases](https://github.com/lawtszwah/boss-greeting-assistant/releases) 下载 `boss-greeting-assistant-v0.1.1.zip` 并解压；或自行构建：`npm ci && npm run build`，生成 `dist/`。
2. Chrome 打开 `chrome://extensions`，开启「开发者模式」，「加载已解压的扩展程序」选择解压后的文件夹或 `dist/`。
3. 在 BOSS 直聘平台的「消息通知 - 设置招呼语」中开启默认招呼语。
4. 打开岗位搜索页并选好城市，点击扩展图标，阅读并确认风险说明，填写设置后点「开始」，核对摘要（尤其是排除关键词和本次最多发送数）后点「确认开始」。
5. 结果不明的岗位会进入「待核对」，请在平台上确认后标记；插件不会自动重发。

首次在真实账号上试用时，建议把本次发送上限设为 1。修改代码或更新扩展后，在扩展管理页重新加载，并核对卡片上的版本号。

## 开发与版本控制

- 运行环境：Node.js 20 及以上。安装开发依赖：`npm ci`（jsdom 用于模拟页面测试，esbuild 用于打包）。
- 运行测试：`npm test`。打包：`npm run build`，输出到 `dist/`，在 Chrome 扩展管理页开启开发者模式后「加载已解压的扩展程序」选择该目录。
- `src/core/` 为不依赖浏览器 API 的业务规则与状态层；`src/page/` 为页面适配；`src/runner/` 为任务执行器。

- `main` 保存经过检查的文档和可用版本。
- 功能开发使用 `codex/` 前缀分支，通过 Pull Request 合并。
- 当前版本 `v0.1.1`；PRD 文档版本 `0.3`。
- 不提交账号凭据、浏览器资料、真实简历、聊天记录、个人投递历史或含个人信息的截图。

## 使用边界

本项目与 BOSS 直聘无隶属或合作关系。自动化操作存在账号限制或封禁风险；任务额度和操作间隔不代表平台允许或保证账号安全。遇到验证码、访问限制或登录失效时停止，交由用户在原平台处理，不绕过平台限制。
